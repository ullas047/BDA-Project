# Report handover checklist

Create the final IEEE-format PDF (maximum 15 pages plus appendices) in this folder. Cover page: group number, names/IDs, repository URL, video link. Required sections: problem/CEP conflicts; architecture; data/quality/lineage/privacy; analytics; evaluation; dashboard; ethics; limitations; references. Appendices: two-page policy brief, signed contribution matrix, and half-page reflection per member. See the assignment brief for exact handover requirements.
