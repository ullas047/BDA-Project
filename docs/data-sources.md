# Public data sources

## Bangladesh district boundaries

The dashboard choropleth uses the 64-district ADM2 GeoJSON from geoBoundaries, release `BGD-ADM2-16705992` (2020). geoBoundaries identifies the source as Bangladesh Bureau of Statistics and OCHA ROAP, licensed CC BY 3.0 IGO. The bundled simplified geometry is stored at `dashboard/data/bangladesh-districts.geojson` to keep the dashboard usable offline.

Source metadata: https://www.geoboundaries.org/api/current/gbOpen/BGD/ADM2/
